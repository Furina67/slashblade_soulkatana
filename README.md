## 一、模组简介

- **名称**：拔刀剑附属·魂刀
- **模组 ID**：`soulkatana`
- **前置**：SlashBlade（拔刀剑：重锋）；可选软前置：Identity（化身）

## 二、玩法设计

> “魂刀”是一类通用载体：把不同世界观中的角色、能力与设定，以拔刀剑附属形式引入游戏。

### 魂刀·两面宿傩

- **稀有度**：EPIC
- **攻击伤害**：8
- **攻速**：1.6

**左键**
- 未打中实体 → 施放 **[解]**（替换掉原版挖方块行为），附带 **[冷却]，持续 2 秒**
- 打中实体 → 不施放特殊攻击，为普通攻击

**右键**
- 打中实体 → 施放 **[捌]**，附带 **[冷却]，持续 2 秒**
- 未打中实体 → 不施放特殊攻击，为普通攻击

**[领域展开]**
- **按下鼠标中键（可自定义）**
- 音效：**按下中键后先完整播完咏唱音 `malevolent_shrine`（约 4.6 秒），
  音频播完才开始后续程序**（30 tick 前摇 → 展开并播 `domain_expand`）；
  时长由服务端解析 OGG 头部得出，与真实音频严格对齐。
  咏唱期间：再按中键无效；收刀/死亡/下线会**停掉未播完的咏唱音**并中止，不进入前摇；
  咏唱音纳入停音名单，领域关闭/取消/界主下线时与展开音一并停播，不会残留

**数值说明**：原版 SlashBlade 所拥有的（除锻造数以外的）杀敌数、荣耀值等属性，本刀全部具备；
并**额外拥有“手指数”**

### 物品二：两面宿傩的手指

- **稀有度**：紫色字体
- **获取**：**结构中的宝箱有 20% 概率**出现
- **食用效果**：食用后**立刻死亡**
- **死亡信息**：`<玩家名> 不配当诅咒之王的受肉体`

### 魂刀·真人

- **攻击伤害**：6
- **攻速**：1.6
- **合成**：无铭刀「木偶」（`slashblade:slashblade_wood`）+ 2 × 改造人

**右键击中生物 → [无为转变]**
- 装载「化身」(Identity) 且联动挂接成功：**弹出 Identity 原生的化身选择界面**，
  **玩家选中的化身施加到被击中的实体上**（单人 / 局域网 / 专用服务器行为一致）；
  该界面**打开即暂停游戏**（单人/局域网，由套在 IdentityScreen 外层的
  `PausableIdentityScreen` 实现，不改 Identity 源码），开界面时播放一次
  `idle_transfiguration`；**选择完毕（应用或取消）后由服务端下发关屏包自动关闭界面**
- 未装载 Identity（或钩子挂接失败）：被击中的实体**随机变成一种生物**（boss 类除外）
- **对 boss 与傀儡（铁/雪/铜傀儡及各类 golem）不生效**
- **平衡：每个实体一生只能被转变一次**——转变产物身上带持久标记（随存档保存），
  再对它右键会被拒绝；取消选择 / 目标消失不算用过，仍可再施
- 与宿傩刀共用 2 秒[冷却]

**中键 → [领域展开·自闭圆顿裹]（真人刀专属）**
- 手持真人刀按中键（与宿傩刀的中键按手持刀分流，各开各的领域）：30 tick 前摇，
  在界主位置播台词 `self_embodiment_of_perfection_voiceline`；展开时播
  `self_embodiment_of_perfection`，画暗红（0xA01010）尘粒子边界环——只有边界粒子，
  不加渲染层/着色器，不破坏地形
- **封闭式上半球穹顶**：中心在界主脚下，半径 64 格；判定为球（含 Y 轴）且只取上半：
  `dx²+dy²+dz² ≤ R² 且 target.Y ≥ 界主.Y`（区别于宿傩领域的纯水平圆判定）
- 展开瞬间对半球内除界主外的一切活物挂 BUFF **[触及灵魂]**（纯标记，无任何视觉与提示），
  领域存续期间每 tick 维护时长，出半球/领域关闭即时摘除
- **全域必中**：领域存续期间界主每一次"发起攻击"——包括对空气/方块的空挥
  （客户端左键 MISS/BLOCK 上报 `ACTION_DOMAIN_ATTACK`，空挥必中不以
  AttackEntityEvent 为唯一入口）——都对半球内所有挂 [触及灵魂] 的实体各结算一次
  必中伤害；左键真正命中的那只由原版近战结算，不重复吃
- **必中伤害 = 完整复刻原版近战 + 强制扣血**：攻击力面板（力量药水 +3/级走 vanilla
  属性修饰符，已含在面板内）、锋利附魔增伤、蓄力倍率 `getAttackStrengthScale`、
  暴击 ×1.5、火矢点燃逐项同原版 `Player.attack()`；`hurt()` 前清零无敌帧，事件层把
  护甲/抗性/吸收减伤全部作废（LivingHurtEvent 记原始伤害 → LivingDamageEvent 改写回
  并退还吸收心）——实打实扣血，死亡动画/掉落/统计保留（不直接 setHealth）
- 再按一次中键关闭；界主死亡/换维度/下线/走出半球自动收尾；与宿傩领域共用 30 秒冷却
  （`SoulbladeDomainCd`）

**[冷却]**：施放 [解]/[捌]/[无为转变] 后 2 秒内——
- [解]/[捌]/[无为转变] 无法再次施放（动作栏提示剩余秒数）；
- **普通攻击（左右键挥斩）完全不受影响**——冷却只锁特殊攻击；
- 对其他武器无影响。

**持有联动**：装载「化身」(Identity) 时，**主手持「魂刀·真人」才能获得 / 切换化身**
——覆盖快捷键界面、`/identity` 命令、击杀解锁等全部路径（服务端权威否决，静默无提示；
客户端侧同样有开屏闸门：不持刀时连化身界面都弹不出来；
变回玩家本人永远放行，不会把玩家锁在生物形态）。
开关：`identity.identity_require_soul_blade`（布尔值，默认 `true`）。
配置文件位置：单人存于 `saves/<存档>/serverconfig/soulkatana-server.toml`，专用服务器为 `config/soulkatana-server.toml`；
也可在「Mod 设置」界面里直接改。

**自查指令**：`/soulkatana status` 打印——Identity 是否装载、变身审核钩子是否挂接成功
（失败时给出原因摘要）、变身闸门开关、当前剩余[冷却]。
判定"联动到底通没通"先看这条指令的输出。

### 物品三：改造人

- **获取**：**雪屋地下室的宝箱固定刷新 4 个**（位置随机，数量恒为 4）
- **用途**：合成「魂刀·真人」

### 软依赖：化身（Identity）

- modid `identity`，**非必需**：未装载时模组照常运行，只失去上述变身联动
- 实现方式：挂 Identity 官方的 `IdentitySwapCallback` / `UnlockIdentityCallback`
  变身审核钩子（全反射，编译期与运行期都不需要 Identity 在 classpath 上）
- 挂接时机：`FMLCommonSetupEvent` 首次尝试；若失败，会在**首次施放[无为转变]时自动重试**
  （懒加载）。是否挂上以 `/soulkatana status` 为准

## 三、构建

```bash
gradle build
```

构建产物位于 `build/libs/soulkatana-1.20.1-1.1.0-r6.jar`。

> 首次构建需网络下载 Forge 47.4.0 依赖（`maven.minecraftforge.net`）；
> 依赖下载齐全后可 `gradle build --offline` 离线构建。
