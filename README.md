## 二、玩法设计

> “魂刀”是一类通用载体：把不同世界观中的角色、能力与设定，以拔刀剑附属的形式引入游戏。
> 本版本先实装《咒术回战》· 两面宿傩相关内容，后续可继续扩展其他世界观。

### 术语定义

| 术语 | 效果 |
|------|------|
| **[冷却]** | 使特殊攻击无效化（无法放出），**不影响**左右键的普通攻击 |
| **[解]** | 在玩家面朝方向**横 3 格、竖 2 格、长 8 格**内的实体受到 **8 点（4 颗心）远程伤害**；同时以**横 3 格、竖 1 格、长 8 格**的**白色粒子**组成**月牙状**，向前推进，速度较快 |
| **[捌]** | 对目标**首次**使用时减少其 **10% 当前血量**（采用**进一法**）；对该实体**再次**使用 [捌] 时，改为造成 **8 点（4 颗心）近战伤害** |

### 物品一：魂刀·两面宿傩

- **稀有度**：紫色字体（同附魔金苹果）
- **攻击伤害**：8
- **攻速**：1.6

**左键**
- 未打中实体 → 施放 **[解]**（替换掉原版挖方块行为），附带 **[冷却]，持续 2 秒**
- 打中实体 → 不施放特殊攻击，为普通攻击

**右键**
- 打中实体 → 施放 **[捌]**，附带 **[冷却]，持续 2 秒**
- 未打中实体 → 不施放特殊攻击，为普通攻击

**[领域展开]**
- 快捷键：**按下鼠标中键**

**数值说明**：原版 SlashBlade 所拥有的（除锻造数以外的）杀敌数、荣耀值等属性，本刀全部具备；
并**额外拥有“手指数”**（可理解为魔改版锻造数）。

### 物品二：两面宿傩的手指

- **稀有度**：紫色字体
- **获取**：**结构中的宝箱有 20% 概率**出现

## 三、构建

```bash
gradle build
```

构建产物位于 `build/libs/soulblade-1.20.1-1.0.0-r5.jar`。

> 首次构建需网络下载 Forge 47.4.0 依赖（`maven.minecraftforge.net`）；
> 依赖下载齐全后可 `gradle build --offline` 离线构建。
